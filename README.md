# Дополнительные материалы к статье М. Г. Козловой «Псевдобулева оптимизация с ДНФ-ограничением по качественным знаниям…»

Программы, данные и результаты всех вычислительных экспериментов статьи:
рис. 2 и табл. 1 (трудоёмкость GAEL/LAEL), утверждения 1, 3, 4 (корректность и оценки
DS-алгоритма), разд. 3 (алгоритм 7 и стратегии опроса), теорема 6 и утверждение 10
(алгоритм 8), разд. 6 (модельная задача, табл. 6, сравнение с решателями).

| `src/encode.py` | кодирование для внешних решателей: ДНФ (селекторы) и ЛПС (односторонняя полнота Кларка); форматы OPB, LP, WCNF |

## Обозначения статьи и имена в программах

Имена в программах, столбцах CSV и ключах данных следуют обозначениям статьи (версия 9).

| Статья | Смысл | В программах |
|---|---|---|
| $\nu(S)$ | число продукций ЛПС | `LPS.nu`, столбец `nu` (`fig2.csv`, `table6_rows.csv`) |
| $\Lambda$ | множество пар (литерал, предки) в строке $(T,\Lambda)$ D-алгоритма | `Lam` (`lps.d_algorithm`) |
| $\Pr(a)$ | предки вхождения литерала | `Pr_a`, `Pr_c` |
| $D_x$, $\lvert D_x\rvert$ | ДНФ литерала $x$ и число её конъюнкций | второе значение `ds_algorithm` — словарь `D_size`; столбцы `D_size`, `sum_D_inter`, `omega_per_D`, `sum_D` |
| $\lvert D\rvert$ | число конъюнкций ДНФ (табл. 7) | столбец `D_size` (`solvers_rows.csv`, `summary_solvers.csv`) |
| $\tau(x)$ | число деревьев вывода | функция `tau` (`exp_lps_verify.py`) |
| $\Omega_j$ | интервал конъюнкции $K_j$ | конъюнкция `K` из списка `D` |
| $P^{\pm}=P^+\cup P^-$ | номера переменных с $c_i\ne0$ | `Ppm` (`alg7.build_PiA`) |
| $M'$, $M'_t$ | число классов $\Pi(\mathcal A)$ и в блоке $\Gamma_t$ | `Problem.Mprime`, столбец `Mprime`; `block_sizes`, `Mprime_t`, `Gamma` (`generators.product_classes`) |
| $\lvert\mathrm{supp}\,d\rvert$ | число ненулевых компонент запроса | `supp` (`alg7.strategy_g`) |
| $\widetilde P_0^{+}$, $\widetilde P_0^{-}$, $Z_0$, $\mathrm{Conf}$ | множества разд. 5 | `Pt0_plus`, `Pt0_minus`, `Z0`, `conf` (`pareto.py`) |
| $\underline f(X)$, $\overline f(X)$ | нижняя и верхняя векторные оценки | `f_lo`, `f_hi`, функция `f_bounds` |
| $c_{ji}$ | коэффициенты критериев | массив `c[j, i]`, ключ `c` в `alg8_tasks.jsonl` |
| $E$, $C$ | эффект и затраты (разд. 6) | `e`, `k` (коэффициенты $e_i$, $k_i$) |
| $k_\vee$, $k_\&$, $\mu_h$ | степени ИЛИ- и И-вершин, оценка утв. 4 | `kv`, `ka`, `mu` |
| семейства «ДНФ», «БЗ» табл. 7 | | `DNF`, `KB`; крупные ЛПС — `KB-large` |
| группы 1, 2 алгоритма 7 (прил. А.3) | | значения `1`, `2` столбца `group` |

Прочие сокращения в CSV: `omega` — $|\Omega|$, `rbar` — $\bar r$, `rstar` — $r^*$,
`dbar` — $\bar d$, `ratio` — DS/D, `g` / `seq` / `css` — число запросов правила (6),
последовательного сравнения и стратегии текущего решения в худшем случае.

## Воспроизведение

Требуется Python ≥ 3.11, NumPy ≥ 2.0, SciPy ≥ 1.11 (HiGHS входит в SciPy).
Для сравнения с решателями — исполняемые файлы HiGHS, SCIP, OR-Tools `sat_runner`
и пакет PySAT. Пути задаются в `scripts/solvers.json`: `highs`, `scip`, `cpsat` —
исполняемые файлы, `pysat` — каталог, добавляемый в PYTHONPATH для RC2 (`"."`, если
PySAT установлен), `pbcomp` — решатели формата PB Competition с шаблоном команды.
Решатель с пустым путём пропускается.

```
python3 scripts/exp_fig2.py        # рис. 2, табл. 1: точные формулы, наклоны    (< 1 мин)
python3 scripts/exp_lps_verify.py  # утверждения 1, 3, 4                           (~10 мин)
python3 scripts/exp_table6.py      # табл. 6                                      (~2 мин)
python3 scripts/exp_eco.py         # модельная задача разд. 6, 60 ЛПС для алг. 8  (~1 мин)
python3 scripts/exp_alg8.py        # теорема 6, утверждение 10: 500 задач        (< 1 мин)
python3 scripts/exp_alg7.py        # стратегии опроса, 60 задач                   (~15 мин)
python3 scripts/exp_css_ties.py    # CSS и разрешение ничьих                       (~20 мин)
python3 scripts/exp_solvers.py DNF KB   # табл. 7: сравнение с решателями          (~45 мин)
python3 scripts/exp_solvers.py KB-large # крупные ЛПС, только решатели            (~1 мин)
python3 scripts/summarize.py       # сводная табл. 7: results/summary_solvers.csv
python3 scripts/dump_instances.py  # сохранить экземпляры разд. 6.3 и G2 в data/
```

Все генераторы детерминированы: задача восстанавливается по зерну
(`numpy.random.default_rng(seed)`), а для независимости от версии NumPy сами задачи
сохранены в `data/`. Подсчёт операций (рис. 2) детерминирован и не зависит от
платформы; время работы — зависит.
